# Product Overview

Z-TD is a PixiJS tower defense game. Players place and upgrade towers to defend against zombie waves.

## Gameplay
- Grid-based tower placement along a path
- Resources: money, wood, metal, energy (passive generation)
- Sell towers for 75% of total cost (base + upgrades)
- Wave-based progression with increasing difficulty

## Game States
Main Menu → Level Select → Playing → Wave Complete → Paused / Game Over / Victory
