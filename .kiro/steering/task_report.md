# Documentation Guidelines

## Task Reports
- Only create when explicitly requested or after verifying a feature works
- Location: `Docs/task_reports/`
- Filename: `DD-MM-2025_[Name].md`
- Merge into existing doc if same topic

## Doc Folders (only these 4 exist)
| Folder | Content |
|--------|---------|
| `Docs/task_reports/` | Task reports |
| `Docs/Code_Tech_Docs/` | Technical/code docs |
| `Docs/Art_Docs/` | Visual/art docs |
| `Docs/Design_Docs/` | Gameplay design — **read-only, user edits only** |

## Live Links
Use `#[[file:<relative_file_name>]]` to link to referenced files.

## Index
Maintain `Docs/task_reports/00_INDEX.md` — list all reports with links.
