Design pillars
I’d add 3-4 non-negotiable pillars near the top of the GDD, because they will improve both brainstorming and scope control. A strong set for Z_TD could be: “Readable under pressure,” “Multiple solutions per threat,” “Runs reward adaptation,” and “Depth through interaction, not raw complexity.”

Those pillars imply concrete rules:

Every zombie threat should have one best counter and at least one acceptable backup counter.

Every wave should teach, test, or twist, not just scale HP.

Every important combat state should be legible at a glance through silhouette, icon, color, and status FX.

Every new feature should create a new decision, not just a bigger number.
